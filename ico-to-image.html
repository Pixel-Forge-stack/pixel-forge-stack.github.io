The Formats

What Is in an ICO File?

An ICO file is a container that can hold several versions of the same icon at different sizes, commonly 16 × 16, 32 × 32, 48 × 48 and 256 × 256. Windows and browsers pick the size that suits the context. Each entry is stored either as a PNG image or as an older bitmap format.

What Changes

What the Tool Extracts

The tool reads the ICO file, lists the sizes it can decode and lets you download each one, or all of them, as PNG or JPG.

PNG keeps transparency and is the safer default for icons.JPG cannot store transparency, so transparent areas are filled with white. JPG is also lossy, so use it only when you specifically need that format.

Some very old icon formats cannot be decoded. Such entries are skipped, and if none can be read the tool shows an error. The extracted images are bitmaps. The tool does not produce vector (SVG) files.

When To Convert

When This Is Useful

It helps when you only have a favicon.ico and need a PNG, when you want to inspect which sizes an icon contains, or when you want to edit an icon in an ordinary image editor. To build an ICO file from an image, use Image to ICO. Larger sizes cannot be created from a small icon without losing sharpness, so use Resize Image only if you accept a softer result.

Common Questions

Frequently Asked Questions

Why can I not open an ICO file in an image viewer? ▾
Many viewers and editors do not read ICO or show only one size. Extracting the images to PNG makes them usable anywhere.
Does each size come out as a separate file? ▾
Yes. Each size is exported on its own, and the Download All button saves them one after another.
Can I convert the icon to SVG? ▾
No. The icon is a grid of pixels. Converting it to a vector needs tracing software, and the result is only an approximation.
Which output should I choose? ▾
PNG, especially for icons with transparent backgrounds.
