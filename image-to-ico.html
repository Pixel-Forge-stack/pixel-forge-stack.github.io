The Format

What Is an ICO File?

An ICO file is a container for one or more small square images of the same icon at different sizes. Windows, browsers and other programs pick the size that suits where the icon is shown, such as a browser tab, a taskbar or a desktop.

How It Works

What This Tool Does

Choose an image, tick the sizes you want (16, 32, 48, 64, 128 and 256 pixels are available; 16, 32, 48 and 256 are selected by default) and download the ICO. Each size is stored as a PNG image inside the file, which modern Windows versions and current browsers read without problems. Very old software may not.

Make the source square. Every size is a square, and the tool scales the whole image into it. A rectangular image will therefore be squeezed. Crop it to 1:1 first with Crop Image.Transparency. Transparent areas in a PNG or WebP source are kept. A JPG has no transparency, so its background becomes the icon's background.Start large. Use a source of at least 256 × 256 pixels so smaller sizes are scaled down rather than blown up. Tiny details disappear at 16 × 16, so simple shapes work best.
Usage

Favicons and Application Icons

Websites commonly list a favicon.ico together with PNG icons of other sizes, and the exact files you need depend on the browsers and devices you target. A favicon.ico placed at the root of a site is still widely recognised. For app-store icons and similar uses, check the platform's requirements, which are usually PNG files at specific sizes. You can produce those with Resize Image to 512 × 512 and related tools. To read an existing ICO, use ICO to PNG/JPG.

Common Questions

Frequently Asked Questions

Which sizes should I include? ▾
16, 32 and 48 pixels cover common favicon and small-icon uses, and 256 pixels is the largest size normally stored in an ICO. The defaults are a sensible starting point.
Why does my icon look blurry? ▾
The source is probably too small or has fine detail. Start from a square image of at least 256 × 256 pixels with simple shapes.
Why is my icon stretched? ▾
The tool fits the whole image into a square. Crop the image to a square first.
Can I use a JPG? ▾
Yes, but a JPG has no transparency, so the icon will have a solid background.
