About

What Pixel Forge Stack Is

Pixel Forge Stack is a collection of small image tools that run in a web browser: resizing, cropping, compressing, format conversion, rotating, watermarking and a few related jobs. The aim is to make common image tasks quick, without installing software or creating an account.

The site does not publish information about its authors or company, and this page does not make claims about them. What it can describe accurately is how the site works.

How It Works

Why the Tools Run in Your Browser

Each tool page is a static HTML page with its own JavaScript. When you choose an image, your browser reads it, the tool draws it onto an HTML5 canvas, and the result is saved as a new file on your device. No server-side image processing is involved, which means the image file is not uploaded to our servers and the tools do not need an account.

Running locally has trade-offs. Speed and memory limits depend on your device, and what a tool can do depends on what your browser supports. For example, the HEIC converter works only where the browser can open HEIC files. Canvas output also means metadata such as EXIF data is generally not carried over to the new file.

Local processing of the image is not the same as the site making no network requests. Pages load fonts, scripts and analytics from third parties; see the Privacy Policy for details.

Principles

What the Site Aims For

Local Processing

The tools process the selected image in your browser, and the image file is not uploaded to our image-processing servers.

Honest Descriptions

Each tool page explains what the tool actually does, including what changes in a conversion and what the limits are.

No Account Required

The tools can be used without signing up. They do not add watermarks or branding to the files you download.

Simplicity

Each tool does one job with a small set of controls, so it is quick to understand.

Project

Maintenance and Costs

The site is built with plain HTML, CSS and JavaScript, with no framework or build step, and is hosted on GitHub Pages. The source is in a public repository at github.com/Pixel-Forge-stack/pixel-forge-stack.github.io, where bugs and suggestions can be reported. The tools are free to use, and the site does not currently load advertising code.
