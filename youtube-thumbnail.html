Thumbnail Size

Which Size Works for a YouTube Thumbnail?

The size commonly recommended for custom YouTube thumbnails is 1280 × 720 pixels, a 16:9 widescreen frame that matches the video player. YouTube publishes its own requirements for minimum width, maximum file size and accepted file types, and they can change, so check its help pages before you upload.

This tool always outputs a 1280 × 720 pixel JPG.

Fit, Fill or Cover

Choosing How the Image Fills the Frame

Cover fills the whole frame and crops away the overflow from the edges. It suits photos where the subject is near the centre.Fit shows the entire picture and adds black bars on the sides or above and below if the ratio differs. Use it when nothing may be cut off.Fill stretches the picture into the frame, which distorts it unless it is already 16:9. It is rarely the best choice for photographs.

If you want control over which part is kept, crop to 16:9 first with Crop Image.

Common Questions

Frequently Asked Questions

What size is a YouTube thumbnail? ▾
1280 × 720 pixels (16:9) is the size commonly recommended, and it is what this tool outputs. YouTube's help pages list the current requirements for minimum width, file size and file types, so check them before uploading.
What do Fit, Fill and Cover do? ▾
Fit scales the whole image to fit inside 1280 × 720 and adds black bars where the ratio differs. Fill stretches the image to exactly 1280 × 720, which distorts it unless it is already 16:9. Cover scales the image to fill the frame and crops whatever overflows, which usually looks the most natural for photographs.
Which file type does the tool create? ▾
A JPG at 92% quality, named youtube-thumbnail-1280x720.jpg.
The file is bigger than YouTube allows. What now? ▾
Thumbnails have a file size limit, which YouTube currently lists in its help pages. Reduce the file with Compress Image, which shows the real size as you adjust quality.
Can I add text to the thumbnail here? ▾
No. The tool resizes or crops a finished image to the 1280 × 720 frame. Add text and graphics in an image editor first.
