How It Works

Convert Images to PDF, Step by Step

Add one or more images, choose a page size and fit, and download a single PDF with one image per page. The PDF is built in your browser using the jsPDF library, which is loaded from a public CDN when the page opens. Your images are not sent to it.

1

Add images

Choose files or drag them in. Any image format your browser can open works, such as JPG, PNG or WebP. Thumbnails appear in the order they will be placed in the PDF.

2

Pick a page size

A4, Letter or A3 for standard pages, or Fit to Image to make each page the size of its image.

3

Set the image fit

Fit keeps the proportions. Fill stretches the image to cover the page.

4

Download

The PDF is saved to your device with every image on its own page.

Settings Explained

Page Size and Image Fit

Page size. A4 (210 × 297 mm) is the standard in most countries, and Letter (8.5 × 11 in) is common in the United States and Canada. A3 is 297 × 420 mm. These pages are always portrait in this tool.Fit to Image. Each page takes the dimensions of its image, so there are no margins. This suits on-screen viewing but not printing on standard paper.Fit vs Fill. Fit scales the image to the page while keeping its proportions, which can leave blank space. Fill stretches the image to the whole page and distorts it unless the proportions match. For scanned documents and anything with text, Fit is normally the better choice.

The tool has no margin, orientation or page-reordering options. If you need one of those, prepare the images first, for example with Rotate & Flip or Crop Image.

Quality and File Size

What Happens to the Images

Each image is drawn onto a canvas at its full pixel size and added to the PDF as a JPEG at 92% quality. That keeps photos and scans looking close to the original, but it is a re-encode rather than a lossless copy.

Two practical consequences follow. Transparent PNGs lose their transparency, and the transparent areas can appear black. And because large photos stay large, the PDF can be heavy. If a portal limits file size, reduce the images first with Resize Image or Compress Image.

Preparing Images

Tips for Documents, Scans and Forms

Check the requirements first. Portals often specify page size, maximum file size and whether one combined file is allowed. Follow those rules rather than the defaults here.Photograph documents flat and evenly lit. Crop away the background and rotate pages upright before converting, so the text is as large and readable as possible on the page.Add the files in order. Because the pages follow the order the files are added, select them in the order you want them to appear.JPG or PNG source? Because the PDF stores JPEG data either way, there is little reason to convert photos to PNG first. Use PNG sources only if you need to edit them elsewhere before creating the PDF.
Common Questions

Frequently Asked Questions

Can I change the order of the pages? ▾
Pages follow the order in which the images were added. There is no drag-and-drop reordering. To change the order, remove an image with the ✕ button and add it again, or clear everything and add the files in the order you want.
Is the image quality kept inside the PDF? ▾
Each image is drawn onto a canvas and saved into the PDF as a JPEG at 92% quality, so photos stay close to the original but are not stored byte for byte. Transparent areas of a PNG are not preserved and can turn black.
Which page size should I choose? ▾
Choose A4 or Letter if the PDF will be printed or if a portal asks for a standard page. Choose A3 for larger sheets. Choose Fit to Image when the PDF is only meant to be viewed on a screen and each page should match its image exactly.
Why is there empty space around my landscape photo? ▾
A4, Letter and A3 pages are portrait. With "Fit (keep aspect ratio)" a landscape image is scaled to the page width, which leaves blank space above and below. Use "Fit to Image" if you want a page that matches the image, or rotate the photo first.
Why is my PDF so large? ▾
File size depends on how many pixels the images contain. Large phone photos produce large PDFs. Resize or compress the images before converting, or use fewer photos per file.
Is there a limit on the number of images? ▾
The tool does not set a limit, but everything is processed in your browser, so very many large images can be slow or run out of memory on a phone or older computer.
